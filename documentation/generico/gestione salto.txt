### Opzione 1: Modifica per una singola stanza (Raccomandata)
  In ogni file di stanza (es. FirstLanding.asm o TheNightmareRoom.asm), il byte all'offset 239 ( FirstLandingUnused:  /  TheNightmareRoomUnused: ) definisce la fisica della stanza nel formato  %GGGGJJJJ :

  •  JJJJ  (4 bit inferiori): Forza/Altezza del salto (Default = 6, imposta 5 per un salto più corto).
  •  GGGG  (4 bit superiori): Preset della gravità:
      •  0  = Gravità 0.5 (leggera)
      •  1  = Gravità 0.75 (standard JSW)
      •  2  = Gravità 1.0 (pesante)


  Esempio di modifica nel file della stanza:
  Se il byte è impostato a  0 , la stanza usa i valori di default (Salto = 6, Gravità = 0.75).
  Per ridurre il salto a 5 mantenendo la gravità standard (Preset 1):

  • Valore binario:  %00010101  ( GGGG = 1 ,  JJJJ = 5 )
  • Valore esadecimale:  $15  (oppure decimale  21 )

  Nel file  .asm  della stanza:

    FirstLandingUnused:
        DEFB $15                          ; Salto = 5 (corto), Gravità = 0.75
    ──────
  ### Opzione 2: Modifica globale per tutte le stanze (Default)

  Se vuoi ridurre la lunghezza del salto in tutto il gioco per tutte le stanze che non hanno un valore personalizzato:

  1. In constants.asm alla linea 39:
    JUMP_STRENGTH:  EQU 5              ; Modifica da 6 a 5 (o 4)

  2. In physics.asm alla linea 1365 ( Phys_LoadRoomSettings ):
    ld   a, 5                          ; Modifica da 6 a 5 per il default di stanza
    ld   (room_jump_strength), a
